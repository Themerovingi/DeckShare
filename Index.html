Add a New Card

Type a card name (e.g. "Steel Seraph") and press Enter or click Add — it'll look it up on Scryfall automatically. Always include the set code when multiple printings exist (e.g. No Mercy + mar for Marvel, not Dominaria Remastered), or paste the full Scryfall card URL. Price and set always follow the exact printing you select.

Click a card name, image, or set to open Scryfall. Price matches the Set/Number printing — paste a Scryfall card URL in Fix URL to change art, set, and price. Use Saved decks for separate lists; Export/Import Library JSON to share all decks.
Data & images courtesy of Scryfall. Edits are saved locally in this browser.

Import Manabox List

Paste a Manabox-style decklist (one card per line: 1 Card Name (SET) 123). Optional *F* for foil. Lines starting with // are ignored. Choose Add to append, or Replace to overwrite the current list.

Import Library JSON

On phone (recommended): open your email attachment as text → Select All → Copy → paste in the box below → tap Import.

Or pick a file: use Choose file if your browser allows it.

Copy Cards to Another Deck

Copy one card (from the Copy button on a row/card) or a batch of favorites/visible cards into another saved deck. Cards are appended — nothing is removed from this deck.
